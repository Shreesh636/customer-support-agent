# GitHub Push Commands

Create a GitHub repository named:

customer-support-agent

Then run these commands from the `Customer_Support_Agent_Final` folder:

```bash
git init
git add .
git commit -m "Add Customer Support Agent n8n project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/customer-support-agent.git
git push -u origin main
```

Before pushing, confirm that no API keys, passwords, tokens, or private credentials are present.

The exported workflow JSON included in this package contains no API key values.
